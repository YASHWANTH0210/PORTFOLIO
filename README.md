# YESWANTH 3D PORTFOLIO

A Minecraft-inspired voxel portfolio for YESWANTH, built with Three.js.

## What's included

- 3D voxel world
- YESWANTH spawn house
- Skills Mine
- Knowledge Library
- Project Workshop
- Study Rooms
- InsideCricket
- My Journey
- Contact Portal
- Day/night cycle
- Interactive panels
- WASD + mouse controls
- Jump + E interaction
- Mobile controls
- GitHub Pages compatible
- No API keys required
- No external image assets required

## Upload to GitHub

1. Open your `PORTFOLIO` repository.
2. Upload `index.html`, `style.css`, `main.js`, and this README.
3. Commit the changes.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Save.
7. Wait for GitHub Pages to deploy.

## Important

The site loads Three.js and the Google font from their CDNs, so the browser needs internet access.

The voxel art is procedurally generated and is intentionally Minecraft-inspired rather than using Minecraft's original assets.

## Controls

Desktop:
- WASD — move
- Mouse — look
- SPACE — jump
- E — interact
- ESC — pause

Mobile:
- On-screen movement buttons
- JUMP
- E / interact
